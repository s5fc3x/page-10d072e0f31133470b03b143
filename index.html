TT 是官方机场吗？如何确认正版？

本站为 TT 唯一官方网站，所有订阅与下载指引均由此发布。请通过本页导航访问，勿轻信非官方渠道以免账号与资金风险。

客户端应该下载哪个？支持哪些系统？

Windows 推荐 Clash Verge 或 v2rayN；macOS 可用 ClashX 或 Surge；Android 用 Clash Meta；iOS 常用 Shadowrocket 或 Stash。路由器可刷 OpenWrt 搭配 passwall。详情见操作说明与下载指引部分。

流量用完会怎样？如何升级套餐？

当月流量耗尽后会限速或暂停高速通道，次月自动重置。可随时在用户中心升级至更高版本，差价补齐即可立即生效，已用流量按比例计算。

旗舰版的 IPLC 和原生解锁有什么优势？

IPLC 为点对点专线，游戏延迟更低、更稳定；原生解锁意味着节点 IP 被流媒体平台识别为当地住宅或数据中心优质 IP，减少验证与无法播放的情况。

年付套餐可以退款或暂停吗？

年付订单在未使用或使用极少流量的情况下，可联系客服申请按剩余月份折算。具体以官方规则为准，建议先体验月付再考虑年付优惠。

多台设备同时在线会冲突吗？

只要不超过套餐设备上限即可同时连接。超出后新设备可能无法认证，建议合理分配。团队版专为多设备场景设计，并提供定制分流。

节点延迟高或无法连接时怎么办？

首先更新订阅并切换其他节点，尝试不同协议。检查本地网络与防火墙。旗舰与团队用户可通过优先工单获得 7x24 技术支持，我们会尽快排查线路问题。
